## T3.1 — `cone_area.py`: closed-form area of solid ∩ disk ∩ wedge (geometry only, no scene)

**Plan**:
- `python/edgebound/cone_area.py` (new). `cone_area_scalar(point, axis_angle, half_angle, H, vertices, edges, background=0) -> float`: plain Python/`math`, a loop over the edges, one edge at a time (the probe's `edge_sector_area` rewritten as own code, `vertices [V,2]` + `edges [E,2]` int, `+ background · area(wedge ∩ disk)` with `area = ½H²·2·half_angle` (`½H²·2π` if `half_angle >= π`)).
- `cone_area(points, axes, half_angle, H, vertices, edges, background=0) -> torch.Tensor [N]`: float64 on the device of `points`, vectorised over the particles (N) and the edges (E) — no Python loop over either (a fixed loop over the 3 wedge 2π-shifts is allowed; `half_angle` is a scalar). The per-edge integral of `½ min(t_e(φ),H)²` over `swept(e) ∩ wedge` is computed by: the chord sub-interval `[c_lo, c_hi] = [l,h] ∩ (pn−be, pn+be)` (be = acos(z/H), the copy of the chord region whose centre is nearest the interval midpoint) → chord `½z²(tan(c_hi−pn)−tan(c_lo−pn))` + sector `½H²` on the two remaining sides. This is algebraically the same as the probe's breakpoints + midpoint test but branch-free over (N,E).
  - `axes [N,2]`: `th = atan2(axes[:,1], axes[:,0])` per particle (a zero vector gives `atan2(0,0)=0`, finite, discarded by the detector). `half_angle` a Python float.
  - Degenerate edge (zero length, or the particle on the edge's line, `|cross| < 1e-300`): contribution 0 (masked). The tangent edge `z == H` is a pure sector (strict `z < H` in the chord test) — the mandatory pitfall test.
  - Units: length² (an area). Sign: positive (an area). `n_w · result` is a count.
- `tests/edge/test_cone_area.py` (new), device `cuda:0` (as `test_cover_scene.py`). Tolerances stated with reasons, written before looking at results:
  * (a) smoke rows from the work document (`atol = 1e-9`; the tangent row `atol = 1e-12`) for both `cone_area_scalar` and `cone_area`.
  * (b) independent oracle: own brute-force midpoint polar grid `1000 × 2000` over disk ∩ wedge (even-odd point-in-polygon, no winding, no edge formula), 10 rows + 120 random (seed 11, SQ/LS/TK in turn, `p` uniform `[−0.6,2.4]²` (`[−0.1,1.1]²` TK), `H` `[0.2,1.2]`, `th` `[−π,π]`, `al=π/6`, every 4th full): `max |diff| ≤ 1e-3·H²` (brute grid error measured 2.95e-4 H² by the reviewer on this recipe; a formula error is ≥ 1e-2 H²).
  * (c) `cone_area` vs `cone_area_scalar`, 300 random (seed 12): `≤ 1e-11·H²` (float64 round-off; (b) is the independent check).
  * (d) degenerate cases vs brute (`1e-3·H²`): vertex `(0,0)` of SQ (`th=π/4, H=0.3`); on-edge `(0.5,0)` (`th=π/2, H=0.3`); particle at distance H from an edge `(0.5,0.5), H=0.5` (`th=0, al=π/6` and full); a zero axis in `cone_area` (finite).
  * (e) negative controls: half-angle × 1.1 vs original exceeds `5e-3·H²` on ≥ 1 of the ten rows; the TK rows with `background=0` differ from brute by `> 0.05·H²`.
