## T1.1 — Q3a exact cover vector (formula verification, no solver change)

**Plan**:
- `python/edgebound/cover.py`: `cover_gradient_mp(verts, x, H)` (mpmath, from core.py `G.prepare(h=1)` + `block_grad`; combination `block_grad(1,H) - H*block_grad(0,H)` = -sum_e n_e ∫_chord (r-H) ds) and `cover_vector_np(points, verts_or_edges, H)` (numpy float64, vectorised over points, own I_1, no mpmath). Both = grad_x ∫_solid K dA, K=(r-H)1[r<=H], units length^2; C_w = n_w x that. Sign: +x comp = +x; above a flat floor points up (away from wall).
- Oracle (independent, polar quadrature, no shared code): grad_x ∫ K = -∫ yhat 1[r<=H] dA = -∫ (y/r) 1[r<=H] dA, y=x'-x. Read `oracle.polar_moment_profile`: it computes ∫_T Y^alpha g(R) dA in units of h, i.e. value = (1/h^2) ∫ y^alpha g(r/h) dA (verified by scaling). So with h=1 and piece (0, H, {-1: 1}) (g=1/r on (0,H)) it returns ∫ (y^alpha / r) 1[r<=H] dA directly in true units. Negative of that, alpha=(1,0),(0,1), is the gradient.
- `.tmp/cover_oracle_test.py`: unit square H=1 x=(0.3,0.4) -> (-0.3457903905, -0.1702249754) vs smoke ref (-0.3457904, -0.1702250): match to ~1e-8. Dictionary piece form (0,H,{-1:1}) IS accepted (no finite-difference fallback needed).
- `.tmp/cover_scale_test2.py`: h=1/piece(0,H) scales as H^2 (ratio 1.000000 for lam=0.5,2,3) -> true units, no extra conversion. (h=H form is scale-invariant and needs xH^2.)
- `tests/edge/test_cover.py`: mp vs oracle <= 1e-12 (rel to H^2); np vs mp <= 1e-12; cases: unit square, L-shape, 30-deg triangle, large square (half-plane-like); inside/outside/near-edge/near-corner/on-edge/poly-in-disk/poly-out-disk/at-vertex; H=1 and H=0.3; 200 random pts (seeded); (i) negative control discontinuous r1[r<=H] edge-only vs central-diff oracle > 1e-3; (ii) flat-floor: C_w up, magnitude vs analytic half-plane (derived in test) and oracle.
