## T1.1 — Q3a: exact wall part of the Barecasco cover vector (formula verification, no solver change)

Background. The free-surface detector sums `C = Σ_j unit(x_i − x_j)` over fluid neighbours within the support `H`; for the wall it uses a continuum of wall particles of number density `n_w`: `C_w = n_w ∫_{solid ∩ r ≤ H} unit(x_i − x′) dA′`, now by polar sampling (`_detect_surface`, `deltasph2d.py` around l.168). Claim to verify: with the **continuous** kernel `K(r) = (r − H) 1[r ≤ H]`,
`C_w = n_w ∇_x ∫_solid K(|x − x′|) dA′ = −n_w Σ_e n_e ∫_{chord(e)} K ds`
where `n_e` is the outward unit normal of edge `e` of the solid polygon (counter-clockwise), `chord(e)` the part of the edge inside the disk of radius `H` around `x`, and `∫_chord K ds = [I_1(s)]_{s_lo}^{s_hi} − H (s_hi − s_lo)` with the odd antiderivative `I_1(s) = (s r + z² asinh(s/|z|)) / 2` (`z = n_e·(p_e − x)`, `r = sqrt(s² + z²)`; at `z = 0` the `asinh` term is 0). There is **no circle term and no indicator term** because `K` vanishes at `r = H`. For the *discontinuous* `r 1[r ≤ H]` the gradient has an extra circle term, so the edge-only formula must **fail** for that kernel (this is what the old note "gradient of K = r" got imprecise; show it).

Do:
1. `python/edgebound/cover.py` with `cover_gradient_mp(verts, x, H)` (mpmath; build it from the existing machinery in `core.py`: read `_prep`, `block_grad`, `_sum_blocks` and reuse `block_grad` for the truncated monomials `r^1 1[r ≤ R]` and `r^0 1[r ≤ R]`; the combination is `block_grad(n=1, R=H) − H · block_grad(n=0, R=H)`; units: lengths in `h` as `core.py` does, state in the docstring what `h` you use and how the result scales) and `cover_vector_np(points, verts_or_edges, H)` (numpy float64, vectorised over points, closed form above, own implementation of `I_1`, no mpmath). Result of both = `∇_x ∫_solid K dA′` (units length²); the function documentation says that `C_w = n_w ×` that and gives the sign convention in one sentence (positive component = points to `+x`; for a particle just above a flat floor `C_w` points **up**, away from the wall).
2. **Independent oracle.** `oracle.py`'s `polar_moment_profile(verts, x, alpha, pieces, h=1, dps=40)` integrates `y^α g(r)` exactly in polar coordinates; its `pieces` accept coefficient dictionaries with negative powers (see `polar_gradient`, which passes `{j-1: -d}`; read it, and note that `polar_gradient` divides by π because kernel pieces carry π, yours do not). `∇_x ∫_T K = −∫_T ŷ 1[r ≤ H] dA′` with `y = x′ − x`: use `alpha = (1,0)` and `(0,1)` with the single piece `(0, H, {-1: 1})` (g = 1/r) in units where `H = 1`, `h = 1`, and convert. Check by reading the code that this is what `polar_moment_profile` computes (log your reading in 3 lines); if the dictionary form is not accepted for your use, say so in the log and use a high-precision central finite difference (step 1e-6, `dps = 40`) of the oracle value of `K` itself instead, with `g = r − 1` on `(0, 1)`.
3. `tests/edge/test_cover.py` — tolerances stated **in the test file with their reason**: mp closed form vs oracle `≤ 1e-12` (relative to `H²`), numpy vs mp `≤ 1e-12`. Cases (at least): a unit square and an L-shaped (non-convex) polygon, a triangle with a 30° acute corner, and a half-plane-like large square; points inside the solid, outside, within `0.05 H` of an edge, within `0.05 H` of a corner, exactly on an edge, polygon completely inside the support disk, polygon completely outside it, `x` exactly at a vertex; `H` = 1 and `H` = 0.3 (scaling check); 200 random points per polygon with a fixed seed. Plus: (i) the **negative control**: for the discontinuous kernel `r 1[r ≤ H]` (edge-only formula `−Σ n_e ∫ r ds` vs the oracle of the corresponding true gradient — obtain the true gradient from a central difference of the oracle *value* of `r 1[r ≤ 1]`, `g = r` on `(0, 1)`) the mismatch must be **larger than 1e-3** for at least one test point, and you report the magnitude and where; (ii) the flat-floor sanity check: solid = large square below the line `y = 0`, particle at `(0, d)`, `d = 0.1H … 0.9H`: `C_w` points up and its magnitude matches the analytic half-plane value (derive it yourself in the test: `∫_{half-disk-complement}` ... or compare against the oracle; state which).
Smoke reference (computed by the reviewer with a throw-away script, independent of your code; use as a first check, not as the test): unit square `(0,0),(1,0),(1,1),(0,1)`, `H = 1`: at `x = (0.3, 0.4)` `∇_x ∫ K dA′ = (−0.3457904, −0.1702250)` (the oracle with `g = 1/r`, `alpha = (1,0),(0,1)` and a minus sign gives the same to 7 digits; the dictionary piece form `(0, 1, {-1: 1})` is accepted by `polar_moment_profile`); at `x = (1.3, 0.5)` it is `(0.5929, 0)`, whereas the edge-only formula for the discontinuous `r 1[r ≤ 1]` gives `(−0.4071, 0)`: that is the circle term you must find in the negative control.
Acceptance: `python -m pytest tests/edge/test_cover.py -q` passes; the report lists, for each case family, the worst error found over all points and its margin to the tolerance, and the negative-control magnitude.
