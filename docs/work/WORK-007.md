## Context (facts established by the reviewer's probes, 2026-10-04; do not re-litigate them)
* **User decision:** a no-slip wall viscosity is wanted (HANDOFF Part A row Q1 wrote `(v_b − v_i)Δλ`; the present forms are free-slip: the ghost velocity mirrors only the normal component). After WORK-006 the solver has `cfg.wallViscosityForm ∈ {"laplacian", "pairwise"}` (both free-slip). This package adds the third value `"noslip"`; nothing else about the existing forms changes.
* **Why not the obvious "constant ghost" no-slip** (ghost velocity `2 v_w − v_i` over the whole solid: `acc = 2 ν_eff wallMass (v_w − v_i) Δλ/ρ`, or the pairwise analogue `2 fac wallMass M₂ (v_i − v_w)/ρ`): measured on a lattice above a wall at rest (`docs/work/refs/review5_noslip_lattice_probe.py`; dp = 1, H = 4, C2, pairwise bulk with ν_eff = 1/8; exact `ν∇²u`: Couette `u = a y` → 0, Poiseuille `u = y(Y−y)`, Y = 12 → −0.25): the total viscous acceleration of the rows z/dp = 0.5, 1.5, 2.5, 3.5 is — Couette: bulk only 0.0962 / 0.0224 / 0.0013 / 0; + constant-ghost pairwise −0.0692 / −0.0743 / −0.0100 / 0; + constant-ghost Laplacian +0.0781 / −0.0451 / −0.0364 / −0.0018 (errors as large as the uncorrected bulk deficit, because the ghost field ignores the velocity gradient: the true extension is the odd *position-dependent* mirror); the ghost-lattice truth (odd extension on a ghost lattice) is exactly 0. **The constant-ghost forms are not accurate no-slip operators**; do not implement them.
* **What works: Chiron et al. 2019, Eq. 91–92** (`docs/derivations/laplacian-wall.md` §8): a wall flux term from a one-sided finite difference of the normal derivative, `(u_i − u_s)/d_n ∫_wall W dS`, `d_n` the distance of the particle to the wall; in the solver's units
  **`acc_wall = −2 ν_eff (v_i − v_w) |G_b| / (ρ_i d_b)`** per body `b`, `ν_eff = α c0 H/(8 ξ)` (the same `fac/8` as the Laplacian form: the ∇² coefficient of the solver's bulk pairwise term), `v_w = b.velocityAt(x_i)`, `G_b` the existing wall gradient of `_wall_data` (`G = wallMass ∇λ`; for a flat wall `|G| = wallMass ∫_chord W ds` — **verified: relative difference 8.6e-16 at z = dp/2** in `small_tank`, `review5_noslip_smoke`), `d_b = max(d_signed, d_min)`, `d_min = 0.25 dx`, `d_signed` from `self.scene.signed_distance(x[near], body=bi)`. Sign: the term opposes `v_i − v_w` in **all** components (no-slip), for a particle on the fluid side. **No new Warp / scene code is needed** (`G` and the distance are already computed in every step). Chiron's `1/γ` renormalisation of the whole operator is **not** used: the solver's bulk term is not renormalised, and the probe below includes the comparison (pairwise bulk + flux, with and without `1/γ`: Couette row 0: 0.0132 vs 0.0195).
* **Measured (lattice probe), pairwise bulk + flux term:** Couette 0.0132 / −0.0137 / −0.0045 / −0.0001 (bulk only 0.0962 / 0.0224 / 0.0013 / 0; target 0); Poiseuille −0.0161 / −0.3707 / −0.2823 / −0.2403 (bulk only 0.9384 / 0.0081 / −0.2271 / −0.2398; target −0.25; ghost-lattice truth −0.150 / −0.233 / −0.240 / −0.240).
* **Measured at solver level** (`docs/work/refs/review5_noslip_solver_probe.py`: `hydrostatic_tank(dp=0.04, domain="surface")`, the solver's own pairwise bulk term, the formula above added outside `rhs`; floor at `y_f = min y − dp/2 = −0.60`, `s = y − y_f`, rows `s = (k + 0.5) dp`, the 15 particles with `|x| < 0.3` per row, ν_eff = 0.00314): Couette `u = s` — bulk only 0.06014 / 0.01405 / 0.00084 / 0.00004, **with the flux term 0.00815 / −0.00855 / −0.00280 / 0.00001**, target 0; Poiseuille `u = s(0.36 − s)`, target `−2 ν_eff = −0.00628` — bulk only 0.01625 / −0.00147 / −0.00577 / −0.00600, **with the flux term −0.00143 / −0.00825 / −0.00672 / −0.00601**.
* **Known limits (state them in the derivation page, do not "fix" them):** the term is the flat-wall model per particle (one normal `n = G/|G|`, `|G|` the summed wall gradient, `d` the distance to the nearest wall point): near convex corners and on curved walls it is not Chiron's per-element form (per-element `∫W ds / d_n` would need a new per-pair channel in `warpbc` — phase 2); `d_min` caps the `1/d` singularity (the no-penetration law keeps particles at `d ≳ 0.25 dx`); the term is an explicit damping with rate `k = 2 ν_eff |G|/(ρ d)` (`≈ 5 s⁻¹` for the dam break at `d = dx/2`, `H = 4 dx`): the time step of the solver is acoustic, `k·dt ≪ 1`; T7.2 measures it.
