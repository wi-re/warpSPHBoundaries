# Derivation of the curvature-aware boundary integrals

This document records the mathematics behind the closed forms in
`results/symbolic/` (generated by `maple/01_planar.mpl` and
`maple/03_sphere.mpl`) and how they are validated.

## 1. Conventions

Following the paper (Winchenbach, Akhunov, Kolb 2020, eqs. 3–4) and
warpSPHCore (`src/warpSPHCore/kernels/kernel.py`):

```
W(r, h) = C_n / h^n * W_hat(q),     q = r / h,     h = support radius
```

with `W_hat` supported on `[0, 1]` and `C_n` chosen so the kernel integrates
to 1 over `R^n`:

```
2D:  2*pi*C2 * Int_0^1 W_hat(q) q   dq = 1
3D:  4*pi*C3 * Int_0^1 W_hat(q) q^2 dq = 1
```

Kernels (identical shapes in 2D and 3D, transcribed from
`warpSPHCore/scripts/kernels/kernel_specs.yaml`):

| kernel | `W_hat(q)` | C2 | C3 |
|---|---|---|---|
| cubic | `(1-q)^3 - 4*(1/2-q)_+^3` | 80/(7 pi) | 16/pi |
| w2 | `(1-q)^4 (1+4q)` | 7/pi | 21/(2 pi) |
| w4 | `(1-q)^6 (1+6q+35/3 q^2)` | 9/pi | 495/(32 pi) |
| w6 | `(1-q)^8 (1+8q+25q^2+32q^3)` | 78/(7 pi) | 1365/(64 pi) |

Note the cubic-spline shape equals `1/2 - 3q^2 + 3q^3` on `[0, 1/2]` (so
`W_hat(0) = 1/2`, not 1) and `(1-q)^3` on `[1/2, 1]`.

The boundary integral for a particle at signed distance `d` from the
boundary (unit support `h = 1`, particle **outside**):

```
lambda(d) = Int_{D_B(x)} W_hat(q) dx'   (q = |x - x'|)
```

with `lambda = 1/2` on the boundary and `lambda = 0` at the support edge.

## 2. 3-D planar (paper + Wendland extension)

The radius-`q` shell contributes the spherical-cap area
`A(q) = 2*pi*q*(q-d)` for `q in [d, 1]`:

```
lambda_3(d) = Int_d^1 C3 W_hat(q) 2 pi q (q-d) dq
```

**Cubic spline** (paper eq. 18, reproduced exactly by `maple/01_planar.mpl`):
the knot at `q = 1/2` splits the integral:

```
d in [0, 1/2]:  lambda_3 = (192 d^6 - 288 d^5 + 160 d^3 - 84 d + 30) / 60
d in [1/2, 1]:  lambda_3 = -(8/15) (2 d^6 - 9 d^5 + 15 d^4 - 10 d^3 + 3 d - 1)
```

(join at `d = 1/2` is exact: both give `1/30`).

**Wendland**: no knot, so the monomial basis

```
F(n, p, x) = Int_0^x t^p (1-t)^n dt
           = sum_{j=0..n} (-1)^j binomial(n,j) x^(p+j+1) / (p+j+1)
```

closes everything. With `W_hat = (1-q)^n P(q)`, `P = sum c_p q^p`:

```
lambda_3(d) = 2 pi C3 sum_p c_p [ F(n,p+2,1) - F(n,p+2,d)
                                  - d (F(n,p+1,1) - F(n,p+1,d)) ]
```

a **single polynomial in d of degree 2n** (8 / 11 / 14 for w2/w4/w6).
Verified in-script: monomial == direct `int`, `lambda(0) = 1/2`,
`lambda(1) = 0`, 50-digit quadrature.

## 3. 2-D planar (new)

### 3.1 Geometry

Particle at the origin, boundary the line `y = d`, boundary side `y > d`.
The support disk is cut by the line; the radius-`q` shell contributes the
**arc** `s(q) = 2 q arccos(d/q)` (`q >= d`), so

```
lambda_2(d) = Int_d^1 C2 W_hat(q) 2 q arccos(d/q) dq
```

The shell measure carries **one power of q** (not two as in 3-D). This is
the source of the `ln d` terms below, and it fixes the antiderivative in
the by-parts step: `lambda_2(0) = pi C2 <q> = 1/2` requires the single-q
form.

### 3.2 By-parts reduction

Maple cannot close `Int poly(q) arccos(d/q) dq` directly. With
`u = arccos(d/q)`, `dv = 2 C2 q W_hat(q) dq` and

```
v0(q) = Int_0^q t W_hat(t) dt        (ONE power of t)
```

(verified `v0'(q) = q W_hat(q)`), integration by parts gives

```
lambda_2(d) = 2 C2 [ v0(1) arccos(d) - d Int_d^1 v0(q) / (q sqrt(q^2 - d^2)) dq ]
```

`v0(1) = <q> = 1/(2 pi C2)`, hence `lambda_2(0) = 1/2` exactly. The
residual integrals are the `J_m` family:

```
J_m(d) = Int_d^1 q^m / sqrt(q^2 - d^2) dq
```

which closes for every `m >= 1` (the identity
`q^m = q^{m-2}(q^2 - d^2) + d^2 q^{m-2}` reduces `J_m` to
`Int q^{m-2} sqrt(q^2-d^2) dq + d^2 J_{m-2}`, and the same identity applied
in `u = q^2` closes that integral); the seed is `J_1 = sqrt(1-d^2)`:

* **odd** `m`: `poly(d^2) {1, sqrt(1-d^2)}` (e.g. `J_1 = sqrt(1-d^2)`);
* **even** `m`: `poly(d^2) sqrt(1-d^2) + d^2 poly(d^2) ln d
  + d^2 poly(d^2) ln(1+sqrt(1-d^2))`, with `J_0 = ln(1+sqrt(1-d^2)) - ln d`.

Consequences:

* **Wendland w2/w4/w6** — `v0` is a single polynomial, so `lambda_2(d)` is
  one closed form each: `arccos(d)` plus `d * (poly(d^2) sqrt(1-d^2)
  + poly ln d + poly ln(1+sqrt(1-d^2)))`.
* **Cubic spline** — the knot at `q = 1/2` splits the integral;
  *branch A* (`d in [0, 1/2]`) additionally contains `arccos(2d)`,
  `sqrt(1-4d^2)`, `ln(1+sqrt(1-4d^2))` (from the `q = 1/2` boundary
  terms), *branch B* (`d in [1/2, 1]`) has the Wendland shape with
  `W_hat = (1-q)^3`. The join at `d = 1/2` is **exact**:

  ```
  lambda_2(1/2) = (64 pi - 294 sqrt(3) + 249 ln(2+sqrt(3))) / (168 pi)
               approx 0.03748
  ```

Boundary values are exact for all four kernels: `lambda_2(0) = 1/2`,
`lambda_2(1) = 0` (the singular `d^k ln d` terms all vanish at `d -> 1`).

## 4. Solid-sphere boundary (new, Wendland)

Solid ball of radius `R`, particle outside at `d` from the surface,
`D = R + d` from the center. The radius-`q` shell (sphere centered on the
particle) cuts the ball in a circle; the ball-side part of the shell is a
spherical cap. The intersection plane sits at distance
`(D^2 + R^2 - q^2)/(2D)` from the ball center, so the cap height is

```
h(q) = q - (D^2 - R^2 + q^2)/(2D) = (R^2 - D^2 + 2 D q - q^2)/(2 D)
```

and the shell area

```
A(q) = 2 pi q h(q) = (pi q / D) (R^2 - D^2 + 2 D q - q^2),
     q in [d, min(1, D + R)]        (h(q) > 0  <=>  q in (D-R, D+R))
```

Since `D - R = d` and `D + R = 2R + d`, the upper limit gives the **two
branches**:

* **branch 1**, `2R + d >= 1`: `q_max = 1` (support truncates; the usual
  `R >> h` regime);
* **branch 2**, `2R + d < 1`:  `q_max = 2R + d` (support engulfs the ball).

`A(q)` is quadratic in `q`, so the same `F(n,p,x)` basis closes both
branches for the Wendland kernels, and both are **rational with
denominator `R + d`**:

```
lambda_sph(R, d) = N(R, d) / (R + d),      N a polynomial in R, d
```

(branch 1 is at most linear in `R` — `A(q)` is linear in `R` — the exported
`i = 0, 1` rows confirm this; the `i = 1` row is exactly the 3-D planar
Wendland polynomial, which is why `R -> infinity` recovers §2 exactly).

Verified symbolically in `maple/03_sphere.mpl`: monomial == direct
integration with symbolic upper limit `u`; `limit(R -> infinity) == planar`;
branch join on `2R + d = 1`; 50-digit quadrature on both branches.

## 5. Validation strategy

Three independent layers:

1. **Maple, exact arithmetic** (`maple/*.mpl`): every identity above is
   checked *symbolically* (`simplify(... - ...) = 0`), plus 50-digit
   quadrature of the defining integrals at sample points.
2. **Python, 40-digit mpmath oracles** (`src/curvbound/oracle.py`):
   re-integrate the defining integrals from scratch (no shared code with
   the closed-form evaluator `symbolic.py`).
3. **Exact rational + true-2D checks** (`tests/`): boundary values and
   branch joins as `fractions.Fraction` arithmetic; a *genuine 2-D
   Cartesian* quadrature of the disk cut by the chord (no 1-D shell
   reduction); the h-scaling identity
   `Int_{r=d}^{h} (C3/h^3) W_hat(r/h) 2 pi r (r-d) dr = lambda_3(d/h)`.

Observed worst errors (closed form vs oracle, 40 digits):
2-D planar `1.5e-39`, 3-D planar `5.7e-42`, sphere `4.0e-41` (see
`notebooks/demo.ipynb` §5).

## 6. Export formats

`results/symbolic/planar_export.txt`:

```
kernel <name> [n=<m>] [P=<p:c> ...] C2=<a/b/Pi> C3=<a/b/Pi>
planar3d cubic b1|b2 deg=<m>: <coeffs, descending powers of d>
planar3d <w2|w4|w6> deg=<m>: <coeffs, descending powers of d>
planar2d cubic A|B|join: <single-line Maple %a expression>
planar2d <w2|w4|w6>: <single-line Maple %a expression>
```

`results/symbolic/sphere_export.txt`:

```
kernel <name> n=<m> P=<p:c> ... C3=<a/b/Pi>
sph b1 <name>: <i:j:c triples of N(R,d), branch 2R+d >= 1>
sph b2 <name>: <i:j:c triples of N(R,d), branch 2R+d < 1>
```

with `lambda = N(R,d)/(R+d)`. The `planar2d` expressions use only
`Pi, arccos, ln, ^` and rationals; `curvbound.symbolic._eval_maple_expr`
translates them to mpmath (mapping rational literals to `mp.mpf` so no
double-precision contamination enters the 40-digit evaluation).

## 7. Known limitations / next steps

* Only the particle-**outside** case (`d >= 0`). For planar boundaries the
  inside case follows by symmetry: `lambda(d) = 1 - lambda(-d)`.
* Cylinder boundary is the next curved case on the roadmap (see `PLAN.md`).
* The 2-D circle boundary (disk of radius R) is the direct analog of §3
  with a chord shell; same by-parts pattern applies.
* Gradient terms (paper §5.4) are not yet derived.
