Browser GPU diagnostics

This checks WebGPU adapter discovery in the page and in a dedicated worker. It tries both core and compatibility requests, with and without a high-performance preference. No shader is dispatched and no browser settings are changed. Results stay in this page.

Preparing…

If only compatibility requests succeed, the wall explorer can use that adapter while retaining fp32 computation. If the page succeeds but the worker fails, this report identifies a worker-specific restriction. If every request fails, inspect chrome://gpu → Problems Detected, and the GPU/backend entries further down that report. The “WebGPU: Hardware accelerated” summary alone does not prove that a page can obtain an adapter.

Copy the JSON above when reporting an adapter problem. See Chrome’s WebGPU troubleshooting guide.
